# Scout Cam

A smart camera for Android: live viewfinder, scans the scene, names and frames the subject,
shows a level line, and saves photos straight to the Gallery (Pictures › Scout Cam).
Tap the thumbnail to edit the last shot with film looks, adjustments, effects and frames.

**Install:** open the latest release under *Releases* and tap `ScoutCam.apk`.

Every push to `main` builds a new APK automatically (see `.github/workflows/build.yml`).
The UI lives in `app/src/main/assets/www/index.html`.
